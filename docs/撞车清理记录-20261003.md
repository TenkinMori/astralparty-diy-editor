# 撞车清理记录（2026-10-03）

> 背景：这一轮有**两只 agent 同时在写同一个目录**，各自实现了一份"地图模板选择 + 棋盘"，
> 结果 `dotnet build` 报了一堆 `CS0101`（`MapTemplate` 等类型重名）以及引用不全的错误。
> 用户叫停其中一只，并指定 `2529165c` 为**唯一写者**，负责把现场收拾干净。
>
> 这份文档记录**留下了哪一份、删了哪些、为什么**，免得以后对着历史文件猜。

## 一、判断规则

★ **一个概念只能有一个所有者**（一个类型一份定义）。
两份都实现了同一个概念时，**留更完整的那一份**，把另一份的**功能**吸收过去，而不是两套并存。

## 三、我这份被"吸收"而不是"删掉"的东西

1. ★ **`landType → 贴图名` 对照表**（实证：7 张地图 345 个格子）
   - 侦察脚本：`tools\extract_land_textures.py`，原始数据 `tools\land_textures.json`
   - 结论进了 `Art.PlatformTexture`：27 种格子功能，本机 20 种有客户端贴图
2. ★ **`Proto.cs`**（另一只缺的那一块）
3. ★ **`GameMode.bin` 的多层嵌套读法**（`Entries` 要往里钻一层；`Map.bin` 的画板号要走 Mids→场景名）
4. ★ **`CreateFromTemplate` / `SaveDiy`**（官方 json 当底版 + `diy` 块 + 备份/原子替换）
5. ★ **`ShotRunner` 的离屏截图**（不进消息泵、逐页一个进程）

## 四、撞车时被搞坏的文件（教训）

`PageTemplates.xaml.cs` 被我用 PowerShell 5.1 的
`Get-Content -Raw`（按 ANSI 解码）＋ `Set-Content`（按 UTF-8 写回）过了一遍，
中文全变成 `锛?鍒?` 这种乱码，而且**行尾字符被吃掉导致字符串引号不成对**，编译不过。

- 教训：改 `.cs` / `.xaml` **只用编辑工具**，别用 PowerShell 的读写管道过一遍。
- 该文件按原设计重写了一份（`PageTemplates.xaml.cs`），功能点一个没少。
- 留档：`5-DIY关卡\_自测\乱码留档\PageTemplates.xaml.cs.mojibake`
- 顺手写了个还原工具 `tools\fix_mojibake.py`（**只对"简单一次误解码"有效**；
  这次因为原文含私用区字符，编不回去，所以没用上，留着以后防身）。
