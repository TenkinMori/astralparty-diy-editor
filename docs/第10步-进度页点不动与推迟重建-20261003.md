# 第10步：进度页「什么都点不动」—— 病因、修法、验证（2026-10-03）

> 用户原话（逐字）：
> **"进度页面是不是搞错了，怎么什么都点不动了"**

> 一句话结论：**不是被挡住、也不是被禁用、更不是异常 —— 是"按下的那一瞬间页面被整棵重建，
> 正被按着的那颗按钮被换掉了"，于是鼠标抬起没有落点，`Click` 永远不发。**

---

## ① 病因（一句话 + 文件:行）

按下一颗**动态建出来**的按钮时，WPF 的 `ButtonBase.OnMouseLeftButtonDown` 是
**先 `Focus(这颗按钮)`、`OnMouseLeftButtonUp` 才发 `Click`**。那一个 `Focus()` 会把焦点
从「① 上限」输入框拿走 ⇒ 触发：

```
PageStory.xaml:37          LostFocus="OnLimitChanged"
PageStory.xaml.cs:191      OnLimitChanged(...)
PageStory.xaml.cs:214-215      doc.SaveDiy();  MainWindow.RefreshAll();      ← 失焦就无条件刷新
PageStory.xaml.cs:345      条词数值框 box.LostFocus ⇒ AfterEdit（同一类）
MainWindow.xaml.cs:115     RefreshAllCore() →（原来）GoPage(_page)           ← 当场重建
PageStory.xaml.cs:221      BuildList() → ItemList.Children.Clear(); + new Button(...)
```

⇒ 正被按着的那颗按钮**在按下的那一瞬间就从树上没了**（对象身份都换了）⇒
鼠标抬起（MouseUp）没有落点、capture 也跟着没了 ⇒ **`Click` 永远不发** ⇒「点了没反应」。
键盘 Tab 走同理：焦点元素当场被换掉，输入焦点丢到虚空。

**为什么是这一波冒出来的**：第 9 波为了让怪物页实时刷新，把 `DiyNotify.Touch()`
挂在了 `LevelDoc.SaveDiy` 的尾巴上（`LevelDoc.cs:112-113`），并给各页加了
"变回可见就按版本号重建"（`PageMonsters.xaml.cs:32` / `PageBoard.xaml.cs:87` /
`PageStory.xaml.cs:65`）。于是"每一次编辑都会整页重建"成了常态，
**按下瞬间被换掉**的概率从"偶尔"变成"几乎每次"。

**排除项（自查逐条量过，都不是）**：
* 不是被透明层盖住 / 不是 `IsEnabled=false` / 不是 `IsHitTestVisible=false`
  —— 真窗口上做命中测试：**20/20 个能点的地方，正中间命中的都是它自己**；
* 不是"卡住的模态窗把整窗按住" —— `win.IsEnabled = True`；
* 不是 `Reload()` 抛异常导致后续没接上 —— 单独量过 `Reload()` 不抛，
  而且界面与数据逐项对得上（清单条数 / 条词行数 / 数值框数）；
* 不是递归重建 —— `Reload()` 全程不写盘、不 `Touch()`。

## ⑤ 没做到 / 不确定

1. **真人那一支鼠标没被真的按过**：自查用的是"先让焦点离开输入框（= WPF 的 `ButtonBase`
   先 `Focus()` 那一下，用同一个 `LostFocus` 事件喂进去，处理器链是真的）+ 再发 `Click`"。
   窗口摆到屏幕外、**不激活**（不抢用户键盘焦点）⇒ 拿不到真键盘焦点，所以 Tab 那一步同理。
   真·整条鼠标消息链（capture / MouseUp 落点）没有在 OS 层跑过一遍 —— 交给用户实点。
   补救：修完之后 `RefreshAll()` **任何情况下都不再同步重建**，
   所以"按下 / 焦点变化 / Tab"这些时刻不管走哪条路，都不可能再换掉正被操作的那个控件。
2. **进度事件下拉框没得切**：这份演示关卡只有 1 条进度事件（`SelectionChanged` 无事可做），
   只做了命中测试（命中它自己），没做"切换之后编辑区跟着换"的断言。
3. **只修了"重建时机"，没动"失焦就无条件刷新"这件事**：`OnLimitChanged` 现在即使
   值没变也会 `SaveDiy() + 刷新`（只是刷新被推迟）。行为与改前一致，但多了一次无谓的重建；
   这一波按"最小改动"原则没碰它。
4. `--clicktest` 是这一波新加的自查入口，**不在**原来那 127 条里（127 条是老账，一条没动）。
