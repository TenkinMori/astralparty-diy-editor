## 0. 一句话：改了什么

| 之前 | 现在 |
|---|---|
| 新建 = 从官方关卡**摘骨架**（`rounds`/`progress`/`victory`… 全删），只剩 `map`/`difficulty`/`diy` | 新建 = 从**成品模板整份复制**，只换身份键（`difficulty` / `diy`） |
| 真数据在 `diy.events.<id>.items[].effects[]`，另有一份**同步**到 `progress_events` | **只有一份**：玩法内容直接写在服务端读的顶层键里 |
| 胜负条件在 `diy.events.*.victory`（服务端读不到） | 顶层 `victory`（`targets` = **怪物表 id**） |
| 总进度上限在 `diy.events.*.progress_limit`（服务端读不到） | 顶层 `progress.limit` |
| 刷怪 `node` 恒 `-1`、`count` 恒 `1` | `node` = **棋盘上放的那一格**、`count` = **刷几只** |
| 没有"事件奖励" | `progress_events.<id>.rewards[]`（筹码 / 牌 / 钱 / 加扣血，各带 `to`） |
| 事件只能改自带那条（界面没有"新增事件"） | 「＋ 新增事件」= 挑一条官方事件 id 当触发点 |
| 没挂在事件上的怪 = "未配置进度"（校验报错） | = **开局就在场上**（写 `start_monsters`，校验只做说明） |

## 1. 落盘契约（这份文件就是给服务端读的）

```jsonc
{
  "map": 82016,
  "difficulty": 1001,                     // DIY 号段（1001 起，界面不提）

  "rounds": 12,
  "round_award": { "every": 3, "gold": 6, "cards": 1 },
  "progress": { "start": 1, "per_round": 1, "per_death": 1, "limit": 10 },

  "start_monsters": [                     // 棋盘上放了、但没有任何事件指着它的怪 = 开局就在场上
    { "table": 1067, "node": 29, "count": 1, "hp": 10, "defense": 0, "attack": 0, "gold": 6 }
  ],

  "progress_events": {
    "32122": {                            // 键 = 官方 MapEvent id（决定第几点进度播）
      "trigger_progress": 3,              // 编辑器用的提示（服务端不读，靠 id 自己知道）
      "spawn": [
        { "table": 1070, "node": 17, "count": 1, "hp": 22, "defense": 2, "attack": 4, "gold": 10 },
        { "table": 1043, "node": -1, "count": 2, "hp": 8,  "defense": 2, "attack": 4, "gold": 7 }
      ],
      "attack": 1, "defense": 1,
      "rewards": [
        { "kind": "relic", "to": "team",  "choice": 3 },
        { "kind": "card",  "to": "actor", "ids": [20001], "count": 1 },
        { "kind": "gold",  "to": "team",  "amount": 6 },
        { "kind": "hp",    "to": "team",  "amount": -3 }
      ]
    }
  },

  "victory": { "kind": "kill_boss", "targets": [1067] },   // targets = 怪物表 id
  "settlement": { "awards": { "1": 45, "6": 70 } },

  "diy": {                                // ★ 服务端整块忽略，编辑器自己的簿记
    "version": 1, "name": "我的图书馆", "template": "82016_1.json",
    "base_map": 82016, "base_scene": "023", "base_level": "82016_1.json",
    "board": "我的图书馆.board.json", "created": "2026-10-08 12:00:00",
    "monsters": [ { "id": 1, "table": 1070, "hp": 22, "defense": 2, "attack": 4, "gold": 10, "counter": 0 } ],
    "board_monsters": [ { "node": 17, "pool": 1 } ],
    "events": { "32122": { "name": "第一波", "desc": "" } }   // 只有显示名，玩法内容不在这儿
  }
}
```

**读回的规矩**（`DiyPool.Read`）：
1. 池子 / 棋盘先读 `diy.monsters` / `diy.board_monsters`（编辑器自己的账）；
2. 事件优先从 `progress_events` 反推（一条 = 一个事件，事件里只有一条进度条目）；
3. **只有** `progress_events` 不存在时才回落老的 `diy.events.*.items`（老文件兼容）；
4. ★ 棋盘落点只认一处：有 `diy.board_monsters` 就**不**再从 `spawn[].node` / `start_monsters[].node`
   反推 —— 两边都读会让棋盘上的怪**翻一倍**（本轮真踩过，已修 `addRefs = !boardOwned`）；
5. 顶层 `victory` / `progress.limit` 也读回来（一关一个，挂在第一条事件上）——
   不读回来，重开文件之后 ④ 获胜条件和 ① 总进度上限都会是空的。

### 1.1 本轮顺手修掉的三个坑（都是"保存→重开"才知道的）

| 坑 | 现象 | 修法 |
|---|---|---|
| `addRefs` 传反 | 摆好怪 → 保存 → 重开，棋盘上的怪**翻一倍** | `ReadFlatEvents` 里 `addRefs = !boardOwned` |
| 没设触发点时行键退化成条目编号 | 两个"还没设触发点"的事件挤在同一个键上，**后一条内容被吞掉** | 键的优先级改成：`trigger_event` → **事件自己的 id** → 条目编号 |
| `start_monsters` 的"管没管过"判据看的是写盘后的状态 | 用户把棋盘上的怪**全删光**时，模板自带的开局怪残留 | `Write` 开头先算 `managed` 再往下传，管过就整体重写（删光 ⇒ 摘键） |

## 6. 第 12 步之二（2026-10-08 晚）：按事件分组 + 列表不重复

用户实机反馈四条，全是"看得到的问题"，逐条落地：

### 6.1 ★ 会自我放大的写盘 bug（"每个进度显示高达 50 只"）
现场文件 `我的关卡2.json`：`32132` 有 **50 行** spawn，其中 **39 行是同一只怪在同一格的重复**
（`32133` 56/43、`32134` 42/28）。
根因：**棋盘上放 N 格 → 写 N 行 → 读回变 N 条条词 → 再写 N×N 行**，越存越多。
修法（`DiyModel`）：
* `BoardMonsterRef` 加 **`Event`**：每一格上的怪**归属某个事件**（`0` = 开局组 = `start_monsters`）。
  以前"这格属于谁"是**猜**的（谁引用了这只怪就算谁的），同一只怪被两条事件引用时根本没有唯一答案。
* 读回**按怪聚合**：同一只怪在一个事件里只出**一条**条词，只数 = 所有 spawn 行的 `count` 之和。
* 写盘**按格出行**：一只怪在**本事件**下放的每格各一行 `count:1`，外加"计划只数 − 已放格数"的
  一行 `node:-1`（随机补）；只数比格数少时**以格子为准**。
* 开局组：`Event == 0` 的格子 → `start_monsters`；`node<0` 的进 `diy.start_random` 簿记。

### 6.2 界面（用户原话 → 落点）
| 用户说 | 落点 |
|---|---|
| "有多少个就显示几行" | 事件里同一只怪只留一条；再加它 = **数量 +1**（不再堆行）；怪物页同样按怪去重 |
| "删掉…条词" | 删一条「新增怪物」= **连它在棋盘上放的那几格一起撤**（不然"条词删了、棋盘上的怪还在刷"） |
| "怪物列表对不上图标的怪物都删掉，那个是隐藏起来的" | 挑怪窗口只列**有半身像**的怪（`GameTables.MonstersWithAvatar()`，`UT_Monster_Bust_<id>_0` 存在）；已进池子的不受影响 |
| "棋盘那边加个切换进度的功能，切换到这个进度了就显示这个进度刷的怪物，然后放置怪物就是在这个回合放置的" | 棋盘页顶部新增**「刷怪归属」**下拉：`开局就在场上（N 只）` + 每个事件一条；切换只重画（视图状态、不落盘、重建后保留）；**画怪只画当前组**；右键加怪进当前组，当前组是事件时**自动补一条该怪的「新增怪物」** |
| "棋盘里面右键有怪物的格子可以编辑这格里面的怪物" | 右键新增 **「编辑这一格的怪…」**（`CellMonsterDialog`：血/防/攻/星币/反击 + 删掉这只）+ **「拿下这一格的怪（只撤当前组）」**；这一格当前组 0 只时两项都灰 |
