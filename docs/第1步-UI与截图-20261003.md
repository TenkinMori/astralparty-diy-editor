## ② 截图

`D:\小小兔趴\5-DIY关卡\_截图\`（6 张，1440×900，只有窗口本身，不带任务栏/桌面）

| 文件 | 大小 |

| `页2-棋盘.png` | 552,525 B |
| `页3-进度与事件.png` | 322,598 B |

| `页5-校验与保存.png` | 349,829 B |
| `页6-导出与说明.png` | 351,731 B |

做法：离屏渲染（`RenderTargetBitmap` 直接渲视觉树，**不弹窗、不截屏**）。
用法：`DIY关卡编辑器.exe --shots <页码|all> [一份关卡 json]`

★ 上一轮 `--shots` 卡死的原因找到了：它用 `Dispatcher.PushFrame` 等 `ContextIdle`，
而一堆 `GlassSurface` 的 `LayoutUpdated` 会互相触发，永远等不到空闲。
现在改成**同步 `Measure/Arrange/UpdateLayout` + `Dispatcher.Invoke(优先级)`**，
**不 push frame** —— 6 页连着渲只用 **1.6 秒**，没有超时问题。
