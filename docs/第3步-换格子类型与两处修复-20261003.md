## ② ★★ 顺手抓出并修掉的两处真 bug（都不是我改出来的，原来就有）

### bug 1：存盘会把棋盘的顶层 `diy` 块**清空**

`BoardBytes()` 旧代码（`LevelDoc.cs`）：

```csharp
JNode diy = DiyJson.EnsureMember(root, "diy");
diy.Kind = JKind.Object;
if (diy.Members == null) diy.Members = new List<JMember>();
else diy.Members.Clear();          // ★★ 就是这一行
DiyJson.SetInt(DiyJson.EnsureMember(diy, "version"), 1);
... 
```

`diy.Members.Clear()` 把**整个顶层 `diy` 清空**，然后只补 `version` / `base_board` / `note`。
⇒ 只要棋盘文件里还有**别的** `diy.*` 键（比如上一批刚做的 `diy.starts`、`diy.progress_limit`），
**一按保存就全没了**。现在改成"只补缺的三个键，别的原样留着"。

★ 现场验过（`--celltest` 跑真数据）：

```
顶层 diy = 在
   diy.version = 1
   diy.base_board = "023.json"
   diy.note = "底版快照：官方格子类型的原样副本；…"
   diy.starts = [ 4 项 ]
   diy.progress_limit = 21
```

### bug 2：第二次保存会把格子改动**覆盖回官方值**

旧 `BoardBytes(boardSrc)` 的底版永远是 `BoardSrc`（只读的「棋盘缓存」那份）。
于是：第一次保存 ⇒ 写出带改动的 `.board.json`；**第二次保存** ⇒ 又拿"干净的缓存"当底
⇒ 上次的格子改动被抹平。

现在底版优先用**已经存过的那一份**（`<游戏根>\DIY关卡\<名字>.board.json`），没有才拿缓存。

## ③ 落盘形状（`diy` 一律不碰官方 `landType`）

```json
  { "id": 5, "landType": 1, "serial": 1, ..., "diy": { "landType": 8 } }
```
* `nodes[i].landType` = **官方原始事实**，一个字节不动；
* `nodes[i].diy.landType` = 编辑器加的改动 ⇒ **「还原成官方」永远做得到**（删掉那个子键）。
* 还原时如果那个 `diy` 对象空了，连 `diy` 键一起摘掉（不留空壳）。
* ★ 自测 ⑨e：只改 1 格 ⇒ 写出去也**只有那 1 个节点**带 `diy.landType`，官方 `landType` 仍是原值。
* ★ 自测 ⑨f：还原之后带 `diy.landType` 的节点归 **0**，而顶层 `diy` 的键**没被连累**。

## ⑦ 顺手修的一个小坑（参数解析）

`--shots` 认"页码 / 关卡 json"的老逻辑是"看 `args[i+1]`、`args[i+2]` 谁以 `.json` 结尾"。
加了带值的开关（`--board-pick 10`、`--shot-suffix xxx`）之后会**把开关的值当成页码/关卡文件**，
结果渲出一张空状态图（我第一次渲染就踩了，尺寸 203082 那张）。
现在**先把带值开关连它们的值一起标记掉**，再认页码 / 关卡文件。
