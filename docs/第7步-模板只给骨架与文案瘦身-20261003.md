## ③ 一句"新建一个 DIY 关卡后，文件里到底写了什么"

新建 = `<游戏根>\DIY关卡\<名字>.json`，**整份文件就这 3 个顶层键**（实测 365 字节）：

```json
{
  "map": 82016,
  "difficulty": 1001,
  "diy": {
    "version": 1,
    "name": "演示-新建后",
    "base_map": 82016,
    "base_scene": "023",
    "base_level": "82016_0.json",
    "base_level_sha256": "28125c8448224f4c7dab6107459e396b66aa91bf0e6492399582b3854bbd296a",
    "board": "演示-新建后.board.json",
    "created": "2026-10-03 21:13:10"
  }
}
```

* `map` / `difficulty` = 地图 id + DIY 难度号（骨架的身份）
* `diy.base_map` / `base_scene` = 底版图 + 画板号（`023` → 棋盘/贴图都靠它找）
* `diy.base_level` / `base_level_sha256` = 底版是哪份官方 json + 它的 sha256（可回溯）
* `diy.board` = **改动过格子时才生成** `<名字>.board.json`（第一次保存就会写）
* `diy.created` = 建这份的时间

**除了上面这些，其它确实是空的**：
`progress_events` / `start_monsters` / `progress` / `rounds` / `round_award` / `victory` /
`settlement` / `mastermind` 和所有 `note*` 备注 —— **连键都没有**（`⑥b2`/`⑥b4` 就是盯这个）。

★ 为什么是"连键都没有"而不是"写成空数组"：官方 levels 的语义是"没写的字段回落到表/代码
默认值"，而 `start_monsters: []` 会让服务端**真的一只怪都不刷**（不回落）。摘掉 = 回落。
