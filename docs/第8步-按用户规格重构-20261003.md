★ **难度**：文件里写 `difficulty: 1001`（DIY 号段），**界面上一个字都没提**。

**放过怪 + 配过条词之后**（`--demo-edit progress` 的产物，报告 §② 那几张图就是这份）：

```json
{
 "map": 82016,
 "difficulty": 1001,
 "diy": {
  "...": "（上面那些身份键）",
  "events": {
   "1001": {
    "name": "DIY进度",
    "desc": "DIY关卡的配置",
    "items": [{ "n": 1, "effects": [                 // ★ 进度一条带编号 n
     { "type": "给所有人发一张牌", "card": 10001 },
     { "type": "给所有人加扣血", "n": 2 },
     { "type": "给所有人加扣血", "n": -3 },            // 负数 = 扣血
     { "type": "所有人加星币", "n": 10 }
    ] }, { "n": 2, "effects": [
     { "type": "怪物攻击力", "n": 1 },
     { "type": "怪物防御力", "n": 2 },
     { "type": "新增怪物", "monster": 1 }             // ★ monster = 池内序号
    ] }],
    "progress_limit": 18,                             // ★ 总进度上限
    "victory": {                                      // ★ 获胜条件（只两种）
     "kinds": ["击败指定怪物", "击败所有BOSS单位"],
     "targets": [1]                                   // ★ 池内序号（可多个）
    }
   }
  },
  "monsters": [                                       // ★★ 怪物池
   { "id": 1, "table": 1001, "hp": 6, "defense": 0, "attack": 0, "gold": 5, "counter": 0 },
   { "id": 2, "table": 1002, "hp": 9, "defense": 1, "attack": 4, "gold": 6, "counter": 0 }
  ],
  "board_monsters": [                                 // ★ 棋盘上哪一格放池内第几只
   { "node": 17, "pool": 1 }, { "node": 22, "pool": 1 }, { "node": 31, "pool": 2 }
  ]
 },
 "progress_events": {                                 // ★ 服务端真读的那份（同步出来的）
  "2": {
   "spawn": [ { "table": 1001, "node": -1, "count": 1, "hp": 6, "defense": 0, "attack": 0, "gold": 5 } ],
   "attack": 1,
   "defense": 2
  }
 }
}
```

★ **同一只怪放在不同格子上**：`board_monsters` 里 `pool` 都指向 `1`（格 17 与格 22）
—— 池子里只有一条，两格共用；要各写各的属性，就在池子里建两条（同一 `table` 不同 `id`）。
★ **服务端那份**：`新增怪物 → progress_events.<编号>.spawn[]`、`怪物攻击力/防御力 → .attack/.defense`
（这三个键服务端真读）；发牌 / 加扣血 / 加星币三类服务端现在不读，只落 `diy`。
★ **没有 Mutator / 词条这一类**。
